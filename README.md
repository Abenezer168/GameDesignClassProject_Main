# Cyberpunk 2D Autorunner

This is a Geometry Dash-style 2D autorunner we're building for our Game Design and Development class. 

## What we've built so far:
* **The Look:** A custom pixel-art night cityscape background to match our cyberpunk theme.
* **Menus & Screens:** Fully working Main Menu, Options, Game Screen, and a Shop.
* **UI & Navigation:** Smooth button navigation and in-scene toggles. The shop screen is set up with a functional back button and is ready for characters to be added.

## Built With:
* **Unity 6.3** (Version 6.000.3.22f1 LTS — stick to this exact version if you're pulling from our repo!)
* **GitHub** for version control

## Level 1 + Runners (Data Heist update)
* **Level 1 "Neon Rooftops"**: a full auto-runner level that teaches jump, slide, attack and the runner's ability. It has gaps, billboards, Security Drones, Gunner drones, lasers, jump pads, a catwalk bonus route, 2 checkpoints, an alarm-zone finale, the Data Shard and the extraction point.
* **4 runners** (2 men, 2 women), each with a unique W ability: Kai (Kick Thrusters), Nova (Phase Dash), Jax (EMP Pulse) and Lin (Time Glitch). Runners unlock by clearing the level or by spending Data Bytes.
* **The game loop:** Character Select → countdown → HUD (health, Data Bytes, Data Shard, progress, ability cooldown, controls) → pause with volume and **key rebinding** → game over with checkpoint retry → results with S/A/B/C rank, save data and unlocks.
* **Original assets:** pixel art and synthwave music + SFX, all generated by the scripts in `Tools/DataHeistGenerators`.
* **First run in Unity:** use **Data Heist > Setup Project**. Details are in `Assets/DataHeist/README_DataHeist.md`.
* **Browser build:** `Tools/WebPrototype/the-data-heist.html` is playable in any browser.
